TITAN EXCUBAT — REVIEWER EVIDENCE PACK
Published 2026-11-10 at https://github.com/alnitak34/titan-excubat.

CLAIM TO EVALUATE
An experimental NEAR AI provider for DeepSeek Harness that withholds model
content and tool-call chunks until its configured verification checks pass.
It is not a general agent firewall or a tool-permission engine.

WHAT IS REAL AND WHAT IS CONTROLLED
Actual Harness services, production adapter and SDK encryption/signature code
execute in the combined fixtures. Network/TLS I/O, hardware quote checks and
provenance-helper verdicts are controlled fixtures. These tests do not establish
live TEE validation, production availability, exact model identity or safety of
model-generated actions. See the fixture setup and mocks in the source above.
The six source-policy cases separately exercise actual SDK parsing and policy
checks, while Sigstore signatures, certificate parsing and TUF trust are
explicitly simulated. They do not verify genuine signed attestations.

REPRODUCE
1. Without installation or a key, in the source folder:
   node scripts/demo.mjs
   node --test test/*.test.mjs
   This demo uses a simulated SDK and counts chunks, not executed tools.
2. In an approved separate environment where installing packages is permitted:
   npm ci --ignore-scripts --no-audit --no-fund
   npm run test:integration
   Installation needs network access. The test process uses a no-network guard.
   Do not run live inference to reproduce the controlled tests.

SECURITY DISCLOSURE
The 2026-11-10 npm audit reports zero critical/high/moderate entries and three
low package entries for one underlying Elliptic advisory. It remains unresolved;
no patched version was listed. Source: dependency-audit.json and
https://github.com/advisories/GHSA-848j-6mx2-7j84
A zero-count result for other severities is not a security certification.
The historical run also warned about pinned actions targeting deprecated Node 20; it
used forced Node 24 for those actions and succeeded. The TAP logs retain module
mocking warnings. These warnings have not been silently removed.
Scoped dependency-path review and exact proxy source approval are documented in
SECURITY-DISPOSITION.md. Neither the source pin nor the CI results establish
the current remote runtime or complete engine remediation. Post-incident live
deployment verification remains unestablished; see INCIDENT-BOUNDARY.md.
